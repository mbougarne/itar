# التكامل المستمر

[English](../ci.md)

يعمل [مسار التكامل المستمر](../../.github/workflows/ci.yml) عند فتح طلب سحب أو إعادة فتحه، وعند تحديث الفرع الذي أُرسل منه الطلب. تستخدم المهام رمز وصول بصلاحية القراءة. تجمع مهمة **Required checks** نتائج فحوص المستودع والنواة وحزمة React Native وموائم الويب.

| المهمة | ما تتحقق منه |
| --- | --- |
| Repository checks | تفحص صياغة ملفات سير العمل بأداة actionlint والمسافات غير المرغوب فيها في الملفات المتتبّعة، وتتحقق من نقطة بدء بناء CMake، وتدقّق اعتماديات Ruby. |
| C++20 | تبني النواة وتشغّل CTest على Linux باستخدام GCC ثم Clang مع AddressSanitizer وUndefinedBehaviorSanitizer، وعلى macOS باستخدام Apple Clang. ويتحقق مشغّل macOS أيضاً من واجهة الاتصال بين Swift والنواة. |
| مكتبة React Native ومضيف الاختبارات | تبني الحزمة وتفحص الأنواع والشيفرة وتشغّل الاختبارات. تولّد مضيف أندرويد لاختبارات المكتبة وتبني واجهة JNI وملف APK للاختبارات. |
| الويب وWebAssembly | تبني المحرّك باستخدام Emscripten 6.0.13 وتفحص أنواع الويب وتختبر Wasm ومضيف DOM وتثبّت أرشيف الحزمة في مشروع اختبار مستقل. |

لتشغيل الفحوص المتعلقة بتغييرك محلياً، ابدأ بـ[دليل المساهمة](../../CONTRIBUTING.ar.md). وتشرح [أدلة الأجهزة](devices/README.md) كيف تختبر جهاز التحكّم والتأشير والوسائط وتقنيات الإتاحة على المنصة المقصودة. ينتج مسار أندرويد ملف اختبارات APK، ويتطلّب تنفيذ حالاته جهازاً أو محاكياً.

يوجد التطبيق وبناء المنصّات في [مستودع إطار سينما المستقل](https://github.com/mbougarne/itar-cinema). يختبر هذا المستودع المكتبة والمضيف المُولّد لاختبارات التكامل.
