# التكامل المستمر

[English](../ci.md)

يعمل [مسار التكامل المستمر](../../.github/workflows/ci.yml) عند فتح طلب سحب أو إعادة فتحه، وعند تحديث الفرع الذي أُرسل منه الطلب. تستخدم المهام رمز وصول بصلاحية القراءة. تجمع مهمة **Required checks** نتائج فحوص المستودع والنواة وحزمة React Native وتطبيق الويب.

| المهمة | ما تتحقق منه |
| --- | --- |
| Repository checks | تفحص صياغة ملفات سير العمل بأداة actionlint والمسافات غير المرغوب فيها في الملفات المتتبّعة، وتتحقق من نقطة بدء بناء CMake، وتدقّق اعتماديات Ruby. |
| C++20 | تبني النواة وتشغّل CTest على Linux باستخدام GCC ثم Clang مع AddressSanitizer وUndefinedBehaviorSanitizer، وعلى macOS باستخدام Apple Clang. ويتحقق مشغّل macOS أيضاً من واجهة الاتصال بين Swift والنواة. |
| RN workspace | تثبّت الاعتماديات بالإصدارات المقفلة، وتبني الحزمة، وتفحص الأنواع والشيفرة وتنسيق تطبيق التلفاز، وتشغّل الاختبارات. ثم تثبّت أرشيف الحزمة في مشروع مستقل، وتبني حزمة Metro لأندرويد، وتولّد المشروعين الأصليين، وتبني تطبيق أندرويد وواجهة JNI وملف APK الخاص بالاختبارات، وتشغّل فحوص lint. |
| Web / Wasm and TV artifacts | تبني المحرّك المشترك باستخدام Emscripten 6.0.13، وتفحص أنواع الويب، وتشغّل الاختبارات على وحدة Wasm المترجمة وعلى مضيف الويب، وتجهّز مجلدات البناء للمتصفح وTizen وwebOS. |

لتشغيل الفحوص المتعلقة بتغييرك محلياً، ابدأ بـ[دليل المساهمة](../../CONTRIBUTING.ar.md). وتشرح [أدلة الأجهزة](devices/README.md) كيف تختبر جهاز التحكّم والتأشير والوسائط وتقنيات الإتاحة على المنصة المقصودة. ينتج مسار أندرويد ملف اختبارات APK، ويتطلّب تنفيذ حالاته جهازاً أو محاكياً.
