# المتصفح وتلفزيونات Samsung Tizen وLG webOS

[فهرس الأدلة العربية](../README.md) · [English](../../devices/web-tv.md)


يحتوي [تطبيق إطار سينما](../../../apps/probe/web/) على موائم خاص بالويب. تعرض React Native Web الشاشات المشتركة، وتختار نواة C++ المترجَمة إلى WebAssembly وجهات التأشير. يتولّى مضيف DOM قياس العناصر وتمريرها إلى مجال الرؤية ومراقبة تأشير المتصفح. يشترك اختيار الوجهة وتحديث DOM في خيط المتصفح نفسه. يُبنى تطبيق سينما من شيفرة الموائم نفسه الذي تستورده من `@bougarnem/itar/web`. [استخدام إطار في تطبيق آخر](../guides/integration.md#استخدام-إطار-في-تطبيق-ويب-للتلفاز)

## متصفح الحاسوب

استخدم Node 22.23.4 وnpm 10.9.9 وPython 3.10 أو أحدث وCMake 3.20 أو أحدث وMake. تبحث عملية البناء عن **Emscripten 6.0.13** في `build/emsdk` أو في مجلّد SDK الذي يشير إليه `EMSDK`. إذا لم تكن قد ثبّتَّ الإصدار المحدّد، نفّذ الآتي من جذر المستودع لتثبيته في مجلّد البناء المستثنى من Git.

<div dir="ltr">

```sh
git clone --branch 6.0.13 --depth 1 https://github.com/emscripten-core/emsdk.git build/emsdk
python3 build/emsdk/emsdk.py install 6.0.13
python3 build/emsdk/emsdk.py activate 6.0.13
```

</div>

إذا كان الإصدار مثبّتًا، اضبط `EMSDK` على جذر حزمة التطوير التي فعّلتها. يتحقّق البناء من إصدار المترجم ويقرأ إعداداته المحلية. ثبّت اعتمادات مساحة العمل وشغّل التطبيق.

<div dir="ltr">

```sh
npm ci --ignore-scripts --no-audit
npm run web
```

</div>

افتح `http://127.0.0.1:8080`. تبدأ الجلسة الجديدة بكتالوج تجريبي محلي. استخدم نموذج الدخول واختر ملفًا شخصيًا، ثم جرّب الأسهم للتنقّل وEnter للتفعيل وEscape للرجوع. يعمل Tab والمؤشّر أيضًا. في الإعدادات (**Settings**)، أوقِف خيار **TV arrow-key navigation** إذا أردت ترك الأسهم للمتصفح أو لقارئ الشاشة. لإيقاف الخادم اضغط Ctrl+C.

بعد البناء، يمكنك إعادة فحوص الويب فقط بواسطة `npm run typecheck:web` و`npm run test:web`، ويحمّل الأمر الثاني نسخة Wasm المترجمة. شملت اختبارات Chromium وصول المؤشّر إلى الشاشات النشطة، واستعادة التأشير في البحث، والرجوع من محرّر، وظهور التأشير بعد تحميل صفحة بيانات جديدة وتفعيل البطاقات المخصّصة. يمكن فحص شجرة إمكانية الوصول للتحقّق من إتاحة العناصر أو إخفائها. أمّا ما ينطقه القارئ وسلوكه على التلفاز والأداء على الجهاز فتحتاج إلى اختبار منفصل.

للتحقّق من ظهور إطار التأشير في الكتالوج التجريبي، ابدأ من زرّ **Explore title** واضغط السهم لأسفل ثم السهم لليمين. ينبغي أن ينتقل الإطار الفيروزي من بطاقة **Beyond the Atlas** إلى **A Different Tide** وأن يظهر فوق حوافّ الصورة الأربع. اضغط Enter لفتح التفاصيل، ثم Escape للعودة إلى البطاقة نفسها والتأكّد من ظهور الإطار حولها.

<a name="occo-chrome"></a>

### تسجيل التنقّل في Chrome باستخدام Occo

بعد إعداد أدوات بناء نسخة الويب، نفّذ الأوامر التالية ثم افتح `http://127.0.0.1:8080` في Chrome.

<div dir="ltr">

```sh
npm run build:web:engine
node apps/probe/web/build.cjs browser --occo
python3 -m http.server 8080 --bind 127.0.0.1 --directory build/probe-web/browser-occo
```

</div>

1. اختر **Start Occo recording** من إعدادات Cinema. عُد إلى الصفحة الرئيسية واضغط السهم لأسفل من زرّ **Explore title**، ثم السهم لليمين. افتح البطاقة بمفتاح Enter وارجع بمفتاح Escape.
2. ارجع إلى الإعدادات لوضع علامة عند الحادثة أو اختر **Freeze and inspect Occo recording** لتثبيت التسجيل وفحصه. اختر ضغطة مفتاح لترى ما وصل إلى النافذة، وأيّ بطاقة طلبها المحرّك وأيّ عنصر انتقل إليه التأشير فعلاً. تنقّل بين الأحداث بالسهمين لأعلى ولأسفل، ثم اضغط السهم لليمين للوصول إلى **Export recording**.
3. افتح ملفّ JSON في [عارض التسجيلات المحلي](../../../apps/probe/occo/viewer.html) من نسخة المستودع على حاسوبك. يكشف Chrome تأشير الإدخال في الصفحة، أمّا تأشير قارئ الشاشة فيظهر في السجلّ بعبارة «not observed». تؤدّي إعادة تحميل الصفحة إلى مسح التسجيل من الذاكرة. تحتفظ الأداة بآخر 1024 حدثًا وتعرض عدد الأحداث الأقدم التي حُذفت.

### مشكلة معروفة في النقر على بطاقة في الشاشة الرئيسية

على Chromium بدقّة 1280×720، ابدأ من **Explore title** وانقر البطاقة الثانية في **Popular stories**. قد تتلقّى البطاقة التأشير دون أن تُفتح تفاصيلها. في الحالة المرصودة وصل حدث الضغط الأوّلي والتأشير إلى البطاقة، لكن حدث النقر وصل إلى عنصر آخر. فتح Enter التفاصيل، وأعاد Escape التأشير إلى البطاقة ذاتها. العنوان المستخدم في الكتالوج المحلي هو **A Different Tide**.

## تلفزيونات Samsung Tizen

<div dir="ltr">

```sh
npm run build:tizen
```

</div>

يحتوي `build/probe-web/tizen/` على `config.xml` وحزمة التطبيق وأصوله. هذا المجلّد جاهز للتغليف وغير موقّع. استورده كاملًا في مشروع تطبيق ويب ضمن Samsung TV SDK، واضبط معرّف التطبيق وملف التوقيع الملائم للجهاز، وأنشئ حزمة `.wgt` موقّعة للاختبار. يستهدف ملف التعريف Tizen 6.5 ويستهدف بناء JavaScript متصفح Chromium 85. اختُبر تطبيق «سينما إطار» على تلفاز Samsung UE43DU7100UXTK باستخدام جهاز التحكّم عن بُعد والكتالوج المباشر. ونجح اختبار الدليل الصوتي (Voice Guide) على التلفاز نفسه قبل تحسين أداء صفوف الشاشة الرئيسية.

ابدأ على التلفاز بتشغيل بارد للحزمة مع الكتالوج المحلي وتحقّق من تحميل الصور. جرّب مفاتيح الاتجاهات الأربعة وزرّ الاختيار، وزرّ الرجوع Return (رمزه 10009)، ثم اضغط الرجوع مطوّلًا. كرّر مع **Voice Guide** مفعّلًا، وتحقّق من التسميات المنطوقة والتفعيل واستبعاد الشاشات غير النشطة واستعادة التأشير بعد اختفاء عنصر. سجّل طراز الجهاز وإصدار برنامجه الثابت ووسيلة الإدخال.

## تلفزيونات LG webOS

<div dir="ltr">

```sh
npm run build:webos
```

</div>

يحتوي `build/probe-web/webos/` على `appinfo.json` وأيقونة 80×80 وحزمة التطبيق وأصوله. بعد تثبيت webOS TV CLI، ينشئ `ares-package build/probe-web/webos` حزمة `.ipk` يمكنك تثبيتها على جهاز معدّ للتطوير. اختُبر التنقّل في سينما بجهاز التحكّم على تلفاز LG فعلي مع تفعيل **Audio Guidance**.

انتقل إلى بطاقة باستخدام أزرار الاتجاه، ثم استعمل مؤشّر **Magic Remote** ومرّر بعجلته وعُد إلى أزرار الاتجاه. لاحظ العنصر الذي يتلقّى التأشير بعد كل تبديل. جرّب زرّ الرجوع (رمزه 461) من التفاصيل ومن محرّر. فعّل **Audio Guidance** وتحقّق من أنّ كل بطاقة تعرض إجراءً دلاليًا واحدًا واضحًا، حتى بعد تمرير القائمة وإعادة استخدام الخلايا.

</div>
