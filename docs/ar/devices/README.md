# اختبار إطار على أجهزة التلفاز

[فهرس الأدلة العربية](../README.md) · [English](../../devices/README.md)


ابدأ بنظام التشغيل الموجود على جهازك. قد تبيع العلامة التجارية نفسها أجهزة تعمل بـ Android TV أو Fire OS أو VIDAA أو Roku. تختلف أحداث الإدخال وآلية التأشير وقارئ الشاشة باختلاف النظام.

| المنصّة | ما يمكنك تجربته من المستودع | ما لوحظ وما بقي اختباره |
| --- | --- | --- |
| [Android TV وGoogle TV](android-tv.md) | تطبيق React Native TV وموائم Kotlin/JNI، واختبارات أزرار الاتجاه وTalkBack. | جُرّب Chromecast HD مع TalkBack وبدونه. أُبلغ عن قفزات في التأشير عند النزول وعند التحميل. اختُبرت إصلاحات لاحقة في سيناريوهات محدّدة على المحاكي. |
| [Fire TV بنظام Fire OS](android-tv.md#أجهزة-fire-tv-بنظام-fire-os) | تطبيق React Native TV مع موائم Android المكتوب بـ Kotlin/JNI، ويُبنى وفق معمارية الجهاز. | اجتاز الاختبار على الطراز AFTKA (مستوى API 28، ومعمارية `armeabi-v7a`) مع تفعيل VoiceView وتعطيله. وعند تفعيله، شمل الاختبار الانتقال بين الصفوف وبقاء البطاقة المؤشَّر إليها في بداية صفّ التوصيات والتقديم والترجيع عشر ثوانٍ. |
| [Apple TV وtvOS](apple-tv.md) | تطبيق React Native TV مع موائم Swift/UIKit | اجتاز إطار سينما الاختبار على جهاز Apple TV HD مع تفعيل VoiceOver وتعطيله. |
| [متصفح الحاسوب](web-tv.md#متصفح-الحاسوب) | إطار سينما ومضيف DOM ومحرّك C++ مترجم إلى Wasm. | شملت الاختبارات في Chromium لوحة المفاتيح والمؤشّر وشجرة إمكانية الوصول في مسارات محدّدة. لا يزال النطق الفعلي بحاجة إلى اختبار. |
| [Samsung Tizen](web-tv.md#تلفزيونات-samsung-tizen) | مجلّد تطبيق ويب مجهّز للتغليف، مع ملف تعريف Samsung ودون توقيع. | نجح اختبار التنقّل بجهاز التحكّم على تلفاز فعلي مع تفعيل Voice Guide. |
| [LG webOS TV](web-tv.md#تلفزيونات-lg-webos) | مجلّد لتغليف تطبيق الويب مع ملف تعريف LG. | نجح اختبار التنقّل بجهاز التحكّم على تلفاز فعلي مع تفعيل Audio Guidance. |

## إعداد المثال الأصلي

ابدأ بنسخة جديدة من المستودع واستخدم Node 22.23.4 وnpm 10.9.9. يشترك دليلا Android وApple في المثال نفسه المبني باستخدام React 19.2.0 وReact Native TV 0.83.0-0. نفّذ الآتي مرّة واحدة من جذر المستودع.

<div dir="ltr">

```sh
npm ci --ignore-scripts --no-audit
npm run build
npm run native:generate
```

</div>

ينشئ المولّد مشروعَي المنصتين تحت `apps/probe/` ويربط حزم المضيف. ويرفض الكتابة فوق مشروع موجود. احتفظ بالتعديلات اليدوية في الحزمة أو المولّد حتى تظهر عند إعداد نسخة جديدة. اتبع دليل منصّتك لإكمال البناء والتشغيل.

## توثيق نتيجة اختبار

ابدأ بهدف يسهل تمييزه. افتح **Movies** واختر البطاقة **الثانية**، ثم اضغط زر الرجوع من **Details**. أيّ بطاقة يحيط بها إطار التأشير الآن؟ اختيار البطاقة الثانية يكشف الفرق بين استعادة البطاقة نفسها والانتقال تلقائيًا إلى الأولى. ومع قارئ الشاشة، سجّل العنصر الدلالي الذي تلقّى التأشير، والتسمية التي نطقها القارئ، والعنصر الذي فعّله زر الاختيار.

اذكر مراجعة Git ووضع البناء وطراز الجهاز وإصدار النظام والقارئ ووضعه وجهاز التحكّم أو وسيلة الإدخال ومصدر الكتالوج والشاشة التي بدأت منها وتسلسل الضغطات بدقّة. صف الوجهة المتوقّعة وكل تغيّر رصدته. هل كانت الخلية مركّبة أصلًا، أم ظهرت بعد التمرير، أم اختفت أثناء التحميل؟ سجّل أي تمييز مرئي أو نطق عابر حتى إذا انتهت الحركة عند الهدف الصحيح.

لاختبار التحميل، اضغط مطوّلًا أحد أزرار الاتجاه عند آخر بطاقة مرئية أثناء تركيب الصف التالي. لاختبار الإلغاء، اعكس الاتجاه قبل ظهور الوجهة. دوّن القفزات العابرة ثم اضغط زر الاختيار ولاحظ العنصر الذي فُعّل بالفعل. كرّر الاختبار مع القارئ وبدونه.

## أجهزة أخرى

لا تتضمّن هذه النسخة موائمًا قابلًا للتشغيل على المنصّات التالية.

| الجهاز | حالة العمل |
| --- | --- |
| Fire TV بنظام Vega OS | يتطلّب تكامل React Native وC++ مضيفًا خاصًا بـ Vega واختبار VoiceView. موائم Kotlin/JNI يستهدف Fire OS المبني على Android. |
| VIDAA | لم تُحسم آلية العرض أو الإضافات أو تغليف تطبيق الويب، ولا مسار اختباره على الأجهزة. |
| Xbox | يمكن دراسة مضيف ويب متوافق مع المنصّة. يتطلّب التحقّق من إدخال يد التحكّم وقارئ Narrator بناءً يعمل على الجهاز. |
| PlayStation | لم يُحدَّد بعد مسار تكامل مع بيئة تشغيل مُصرَّح بها للتطبيق. |
| Roku | خارج نطاق المشروع. |
