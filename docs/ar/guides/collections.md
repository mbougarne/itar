# إنشاء كتالوج قابل للتمرير

[فهرس الأدلة العربية](../README.md) · [English](../../guides/collections.md)


قد يضمّ الصف 30 عنوانًا بينما ينشئ التلفاز عناصر عرض أصلية لبضع بطاقات فقط. عرّف العناوين الثلاثين كلّها في المجموعة، ليعرف المحرّك أيّ عنصر يلي البطاقة الحالية حتى لو كان خارج الشاشة. يتولّى إطار تنسيق عرض بطاقته والتمرير إليها عند الحاجة.

استخدم `FocusVirtualizedList` لقائمة أفقية أو عمودية واحدة، و`FocusVirtualizedRails` لعدة صفوف أفقية مرتّبة عموديًا. يعتمد المكوّنان على `FlatList` من نسخة React Native الخاصة بالتلفاز. يقبل كل مزوّد شجرة مجموعات نشطة واحدة. اجمع الصفوف المعروضة في تلك الشجرة. [تثبيت الحزمة وبناء أول شاشة](integration.md)

## فيلم واحد في صفّين

يعمل المثال دون صور أو خدمة خارجية. تنقّل بين الصفّين وفعّل كل نسخة من *Paper Moon* بزر الاختيار، ثم قارن المفاتيح المعروضة. معرّف الفيلم واحد، لكن كل بطاقة تحمل مفتاحًا يحدّد موضع ظهورها باستخدام معرّف ثابت للمدخل.

<div dir="ltr">

```tsx
import React, {useMemo, useState} from 'react';
import {Text} from 'react-native';
import {
  FocusProvider,
  FocusVirtualizedRails,
  occurrenceKey,
  type VirtualizedFocusItemRenderer,
  type VirtualizedFocusRail,
} from '@bougarnem/itar/react';

const catalogue = [
  {id: 'featured', entries: [
    {entryId: 'opening', movieId: 'film-7', title: 'Paper Moon'},
    {entryId: 'late-show', movieId: 'film-9', title: 'Night Train'},
  ]},
  {id: 'watch-again', entries: [
    {entryId: 'last-week', movieId: 'film-7', title: 'Paper Moon'},
  ]},
];

const renderTitle: VirtualizedFocusItemRenderer = item => (
  <Text style={{padding: 12, color: '#151515'}}>{item.accessibilityLabel}</Text>
);

export default function Catalogue() {
  const [selected, setSelected] = useState('Choose a title');
  const rails = useMemo<readonly VirtualizedFocusRail[]>(() =>
    catalogue.map(row => ({
      id: row.id,
      items: row.entries.map(entry => ({
        occurrenceKey: occurrenceKey('home', row.id, entry.entryId),
        contentId: entry.movieId,
        accessibilityLabel: entry.title,
        focusStyle: {accentColor: '#006699', backgroundColor: '#bce8ff'},
        onPress: activation => setSelected(activation.occurrenceKey),
      })),
    })), []);

  return (
    <FocusProvider style={{flex: 1, backgroundColor: '#fff'}}>
      <FocusVirtualizedRails
        id="catalogue"
        rails={rails}
        itemExtent={200}
        rowExtent={96}
        viewportExtent={600}
        viewportRows={2}
        rowEntry="first"
        renderItem={renderTitle}
      />
      <Text style={{color: '#111'}}>{selected}</Text>
    </FocusProvider>
  );
}
```

</div>

لعرض صف واحد، استورد `FocusVirtualizedList` واستبدل مكوّن الصفوف بـ `<FocusVirtualizedList id="featured" data={rails[0].items} itemExtent={200} viewportExtent={600} renderItem={renderTitle} />`. تعرض القائمة العناصر أفقيًا تلقائيًا. للعرض العمودي مرّر `horizontal={false}` واستخدم ارتفاع العنصر وارتفاع المساحة المرئية.

## الأبعاد والترتيب ومحتوى البطاقة

| الخاصية | ما تحدّده |
| --- | --- |
| `itemExtent` | العرض الكامل لخلية أفقية أو الارتفاع الكامل لخلية عمودية، بما في ذلك المسافة بينها وبين الخلية التالية. يمكن تحديد عرض خاص لكل صف. |
| `rowExtent` و`viewportExtent` | ارتفاع الصف وعرض نافذة العرض الأفقية عند استخدام عدة صفوف. اضبط حجم الحاوية ليتّسع للنافذة. |
| `viewportRows` | عدد الصفوف المرئية، بين 1 و10. القيمة الافتراضية 2. تحدّد `viewportHeight` الارتفاع الدقيق لنافذة العرض الخارجية عند الحاجة. |
| `rowEntry` | عند التنقّل عموديًا، تختار `nearest` أقرب عمود منطقي مؤهّل. تبدأ `first` بأول عنوان مؤهّل حتى لو تطلّب الأمر عرض خلية جديدة. تعيد `remembered` التأشير إلى آخر بطاقة مؤهّلة رُصد عليها تأشير الإدخال في الصفّ المقصود، وإلّا فإلى أول بطاقة مؤهّلة فيه. |
| `horizontalAlignment` | تُظهر `nearest` البطاقة بالقدر اللازم. تحاذي `leading` العنوان الذي تأكّد التأشير إليه مع حافة البداية، في حدود مساحة التمرير. تضيف `pinned` مساحة بعد آخر بطاقة لتتمكّن هي أيضًا من الوصول إلى حافة البداية. في tvOS، يحدّد UIKit أو VoiceOver البطاقة التي ينتقل إليها التأشير، ويضبط إطار موضع الصف عند حافة البداية. |
| `renderItem` | تتلقّى العنصر وفهرسه داخل الصف. أعد نصًا أو صورة أو عنصر عرض زخرفيًا، أو `null` لاستخدام التسمية وحدها. عند غياب الدالة تستخدم الخلية `item.children`. |
| `onReady` في مكوّن الصفوف | يشير إلى جاهزية نموذج المجموعة النشطة بعد أن يقبله المضيف الأصلي. يفيد في تنسيق الانتقال بين الشاشات. |

احتفظ بالتسمية والإجراء وحالة التمكين على العنصر. تغلّف المجموعة ناتج `renderItem` بمكوّن `Focusable` وتحدّد ترتيبه وأبعاده. إدراج زرّ داخله يضيف أداة تحكّم ثانية إلى بطاقة واحدة. عند تحديث البيانات أنشئ قيمة جديدة بدل تعديل القيمة المنشورة. يمكن لتغيير المظهر وحده أن يعيد استخدام البيانات المنطقية والتسجيل الأصلي نفسيهما.

تصف الأبعاد شبكة ثابتة بوحدات تخطيط React Native. يقيس المضيف الخلايا الفعلية قبل نقل التأشير إليها. تحتاج العناصر متفاوتة الحجم، والهوامش الإضافية للتمرير، والتحويلات الهندسية، ومكتبات العرض الافتراضي الأخرى إلى تكامل خاص. لمزيد من التفاصيل حول عناوين الصفوف وصفّ المقدّمة ومحاذاة اليمين واليسار وملكية الإدخال وخطّافات `FlatList` المدعومة، راجع [مرجع المجموعات](../../../packages/itar/virtualization.ar.md).

## الوصول إلى بطاقة خارج الشاشة

1. ينشر المزوّد مجموعة البيانات المنطقية كاملة بمفاتيح الظهور وترتيبها. يقبل الموائم الأصلي مراجعتها. يظلّ العنصر مسجّلًا في المجموعة حتى إذا أعاد النظام استخدام خلية عرضه لعنصر آخر.
2. تحدّد حركة جهاز التحكّم أو أمر `focusByKey` عنصرًا مؤهّلًا. إذا لم تكن له خلية جاهزة، يطلب المحرّك إظهاره. تضيف المجموعة فهارس المصدر والوجهة المطلوبة إلى نافذة العرض الاعتيادية.
3. ينتظر المضيف اعتماد الخلية الجديدة، ويمرّر إلى الصف ثم إلى العنصر داخله عند الحاجة، ثم يقيس النسخة المعروضة حاليًا. إذا أُلغي الطلب، لا يمكن لنتائج تحضيره المتأخّرة أن تُطلق تمريرًا باسم الطلب الجديد.
4. يطلب المضيف نقل تأشير الإدخال. تكتمل الحركة عند رصد وصوله فعليًا. وبعد انتهاء الطلب تستغني المجموعة عن مناطق العرض الإضافية التي احتفظت بها لأجله.

تسمح المجموعة بما يصل إلى 256 عقدة، تشمل نطاقات القائمة والصفوف. فمثلًا يتطلّب صفّان، لكلّ منهما 20 بطاقة، 43 عقدة هي النطاق الخارجي ونطاقا الصفّين و40 عنصرًا. تستهلك المكوّنات الأخرى في المزوّد جزءًا من سعة السطح الأصلي أيضًا. الحدّ الأقصى لطول المفتاح بعد ترميزه هو 512 بايتًا. تدعم المجموعات المتداخلة مستويين من القوائم. يضيف إطار إلى نافذة `FlatList` المحتفظ بها الخلايا التي يحتاجها الطلب فقط.

إذا بقيت الشاشة في شجرة العرض، فإن `active={false}` على صفوفها يحرّر ملكية المجموعة ويحفظ موضع التمرير. عند تنشيطها يُعاد نشر الكتالوج. استخدم `onReady` ومفتاح الظهور المحفوظ لتنسيق العودة. إذا أُزيل المصدر قبل أن تجهز الوجهة، فقد يختار المضيف عنصرًا آخر. يحتفظ قارئ الشاشة بالتحكّم في تأشير إمكانية الوصول والنطق.
