# حزمة إطار لتطبيقات React Native TV

[English](README.md) · [تثبيت الحزمة وبناء أول شاشة](../../docs/ar/guides/integration.md)

استورد المكوّنات والدوال التالية من `itar/react`. تستخدم النسخة التجريبية React 19.2.0 و`react-native-tvos@0.83.0-0` مع Fabric. لتجربتها في تطبيق آخر، نفّذ `npm pack --workspace itar` من جذر المستودع بعد إعداده، ثم ثبّت الأرشيف الناتج في تطبيق التلفاز وأعد بناء التطبيق الأصلي. ولإعداد tvOS راجع [دليل CocoaPods](apple/README.ar.md).

## تعريف عناصر التركيز

إذا كانت بطاقتك تستخدم `Pressable` من React Native، فاستبدل المكوّن الخارجي للبطاقة بـ `Focusable`. أبقِ الصورة والنصّ داخله، وانقل إليه `onPress` والتسمية التي يقرؤها قارئ الشاشة. تتحكّم خصائص مثل `focusable` و`hasTVPreferredFocus` على عناصر React Native العادية في نظام التركيز الخاص بالمنصّة. يسجّل إطار البطاقة عند تركيب مكوّنه الأصلي. وفي قوائم إطار الافتراضية، تنشئ القائمة هذا المكوّن لكل عنصر وتستدعي `renderItem` لعرض محتواه.

| المكوّن أو الخاصية | طريقة الاستخدام |
| --- | --- |
| `FocusProvider` | يملك سطح التركيز الأصلي، ويربط أوامر التطبيق بما يرصده المضيف. ضَع نطاقات التركيز وعناصره والمكوّنات التي تستدعي دوال الاشتراك داخله. |
| `FocusScope` | يجمع العناصر تحت معرّف محلي ثابت `id`. تحدد الخاصية `layout` طريقة التنقّل بقيمة `row` أو `column` أو `spatial`. وتقبل `boundary` القيم `stop` و`wrap` و`parent`. رتّب العناصر بصرياً باستخدام أنماط React Native. |
| `active`، `entryReady`، `preferredKey`، `restoreOnEntry` | تتيح تعطيل نطاق غطّته شاشة أخرى، أو تأجيل الدخول التلقائي حتى يجهز المحتوى، أو تعيين وجهة مفضّلة، أو استعادة آخر عنصر عند العودة بالأسهم. إبقاء النطاق مثبّتاً يحفظ سجل التركيز الخاص به. |
| `Focusable` | يمثّل عنصراً أصلياً واحداً قابلاً للتركيز. أعطِه مفتاح ظهور ثابتاً `occurrenceKey` ووصفاً `accessibilityLabel` وأبعاداً صريحة. تحدد `order` ترتيبه المنطقي و`enabled` أهليته للتركيز. إذا ظهر المحتوى نفسه في موضعين فلكل ظهور مفتاح مستقل، ولو كان `contentId` واحداً. |
| `children`، `displayLabel`، `focusStyle` | ضَع الصور والنصوص داخل العنصر للعرض فقط. افصل الأزرار والنطاقات الأخرى عنه. يعرض المضيف التسمية عند غياب محتوى مخصّص، ويطبّق نمط التركيز عندما يرصد تركيز الإدخال. |
| `onPress`، `onAdjust` | يحمل حدث التفعيل مفتاح الظهور ومعرّف المحتوى الاختياري والمصدر ومعرّف التثبيت ودورة حياة السطح ورقم التسلسل. وفي عنصر قابل للضبط، يتولى التطبيق تعديل القيمة بمقدار `-1` أو `1` مع مراعاة حدودها. |
| `accessibilityRole`، `accessibilityState` | في أندرويد ومثال الويب، يعرّف الدور `"switch"` مع قيمة منطقية في `checked` مفتاح تبديل لقارئ الشاشة. يستخدم العنصر القابل للضبط دوره الأصلي. لم يُضف إلى مضيف Apple في هذه النسخة دعم مماثل لحالة مفتاح التبديل. |

## رصد التركيز وطلب نقله

حدّد `preferredKey={cardKey}` على `FocusScope` لاختيار بطاقة مفضّلة عند دخول النطاق. وإذا أردت نقل التركيز إلى البطاقة بعد إجراءٍ ما، فاستخدم `focusByKey(cardKey)` التي توفّرها `useFocusCommands()` حين تجهز الوجهة.

تخبرك `useFocusReady()` متى يجهز السطح. تتعقّب `useIsFocused(key, channel?)` ظهوراً واحداً، بينما تعيد `useFocusState(channel?)` حالة آخر رصد ونوعه ومفتاح العنصر إذا كان إطار يديره. حدّد `'accessibility'` لرصد قناة قارئ الشاشة. وقد تعيد `useScreenReaderEnabled()` القيمة `null` حتى تتحدد حالة القارئ.

توفّر `useFocusCommands()` الأوامر `focusByKey(key)` و`restoreScope(path)` و`restoreFocusByKey(key)`، إضافةً إلى فتح مربع الحوار الأصلي المضمّن وإغلاقه. يُرجع طلب التركيز معرّف أمر، ودالة `cancel()`، ووعداً `result`. افحص `status` و`reason` عند اكتماله. الحالات النهائية هي `applied` أو `cancelled` أو `unavailable` أو `unsupported`. رصد المضيف لوصول التركيز يؤكد نجاح الانتقال. يلغي الإلغاء العمل المتبقي، وقد يكون المضيف قد تلقّى بالفعل استدعاءً يغيّر التركيز.

احفظ مفتاح العنصر الذي فتح شاشة التفاصيل. عند العودة، انتظر حتى يجهز النطاق السابق وقائمته. يدعم أندرويد `restoreFocusByKey` لاستعادة ذلك العنصر. إن كان قارئ الشاشة يدير التنقّل، فيجب أن يكون العنصر مثبّتاً ومرئياً ومؤهّلاً بالفعل. تعيد UIKit ونسخة المتصفح `unavailable` لهذا الأمر تحديداً. يظل قارئ الشاشة مسؤولاً عن تركيز الإتاحة والنطق.

للقوائم والصفوف الأفقية المتداخلة، راجع [مرجع القوائم](virtualization.ar.md). ولأمثلة عملية على الاشتراك وانتقال التركيز بين الشاشات وإلغاء الطلبات وتخصيص البطاقات، راجع [دليل الدمج](../../docs/ar/guides/integration.md).
