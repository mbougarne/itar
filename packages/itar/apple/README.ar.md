# مضيف tvOS وواجهة C

[English](README.md) · [البناء والاختبار على Apple TV](../../../docs/ar/devices/apple-tv.md)

تجمع حزمة Apple بين محرّك `C++` وواجهة C وشفرة Swift التي تدير عناصر UIKit، ومكوّنات Fabric المكتوبة بلغة `Objective-C++`. يستهدف ملف podspec إصدار tvOS 15.1 ويستخدم نمط اللغة Swift 5. تستورد وحدة Swift واجهة C التي يعرّفها الملف [ItarEngine.h](ItarEngine.h)، وتبقى إعدادات مُصرّف `C++` محصورة في أهداف CocoaPods.

في تطبيق يثبّت أرشيف الحزمة ويستخدم الربط التلقائي في React Native، أضف السطر التالي إلى هدف tvOS داخل `ios/Podfile`، ثم نفّذ `bundle exec pod install` من مجلد `ios`. يختار الربط التلقائي ملف podspec الذي يحمل اسم الحزمة لهدف Swift الأصلي.

<div dir="ltr">

```ruby
pod 'ItarEngineCore', :path => '../node_modules/@bougarnem/itar'
```

## مسؤوليات المضيف

- عند فتح شاشة جديدة، عيّن `accessibilityPaneTitle` لنطاقها النشط والجاهز، وحدّد زرّ البداية داخله باستخدام `preferredKey`. عند تشغيل VoiceOver، ينقل موائم Apple التأشير إلى الزرّ الظاهر بعد تركيبه مرة واحدة عند دخول الشاشة. ويمكن للمستخدم متابعة التنقّل عند تغيّر التخطيط.
- يدير كل اتصال `EngineConnection` دورة حياة سطح واحد. أنشئه واستخدمه وأغلقه على الخيط الرئيسي. يؤدي التخلص من السطح إلى إلغاء العمل المعلّق. حرّر مقبض C مرة واحدة. إذا استدعى المضيف دوال ردّ أثناء عملية أصلية، فأدرج أحداثها في طابور قبل متابعة تنفيذ أوامر المحرّك.
- تستخدم واجهة C الذاكرة المؤقتة التي يمرّرها المستدعي طوال مدة الاستدعاء فقط، وتنسخ المفاتيح بطول أقصاه 512 بايتاً. يملك المستدعي ذاكرة الخرج الخاصة بالعمليات والإشعارات. افحص حالة استدعاء الواجهة ونتيجة دفعة التحديثات أو الطلب كلّاً على حدة. انسخ العملية المطلوبة، وتحقق مجدداً من هويتها، ثم سجّل إرسالها قبل تنفيذ العمل الأصلي.
- تختار UIKit الوجهة في التنقّل العادي بين عناصر مثبّتة وتدير إيماءات جهاز التحكّم. ويمكن للمحرّك طلب توجيه التأشير إلى وجهة محددة. وفي القوائم ثابتة الأبعاد يستطيع المضيف تمرير الصف إلى عنصر جرى استحضاره للتو وتنسيق الانتقال المنطقي بين الصفوف. يكتمل الانتقال عندما يرصد المضيف تحديث التأشير في UIKit.
- لرصد VoiceOver والتفعيل عبر قارئ الشاشة قناة مستقلة. يمكن للمضيف تفعيل عنصر متاح للقارئ دون تحويل تأشير الإدخال إليه. لاختبار جهاز التحكّم وخيار تقليل الحركة وVoiceOver على التلفاز، راجع [دليل الجهاز](../../../docs/ar/devices/apple-tv.md).

عند تعديل هذا التكامل، ابدأ بملف [EngineConnection.swift](EngineConnection.swift) و[تنفيذ واجهة C](ItarEngine.cpp) و[مرجع القوائم](../virtualization.ar.md).
